# Bank System

A simple console-based banking system built with Python and Object-Oriented Programming.

## Features

* Create bank accounts
* Deposit money
* Withdraw money
* Transfer money between accounts
* Check account balance
* Generate bank cards
* Show card information
* Delete bank cards
* Delete bank accounts
* Save account data using JSON
* Interactive terminal menu

## Technologies

* Python
* Object-Oriented Programming (OOP)
* JSON
* `msvcrt`
* `random`
* `datetime`

## How to Run

Run the following command in the project folder:

```bash
python main.py
```

## About

This project was created to practice Python Object-Oriented Programming by building a simple banking system with account management, transactions, bank cards, and JSON data persistence.
